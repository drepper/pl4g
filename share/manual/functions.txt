Part of [[language]].

                                 destructors, tests and the build function

**A function is defined at the top level** and called by name, through the
module that exports it, through a value, or -- named inside a type -- through
a value of that type: [[expressions.calls]].  Function values and their types
are [[types.functions]], functions written where a value is wanted are
[[expressions.lambdas]], and functions over types are [[types.generic]].

**What the language guarantees of every function**: its arguments are worked
out left to right before it runs; it is pure unless it says otherwise, and
the compiler checks that; a call of itself in tail position takes no stack;
a function with no body is defined somewhere else -- the runtime the compiler
carries, `@[external]`, or the program it is embedded in, `@[host]`
([[running.foreign]]).
