title: Defining operators

Part of [[functions]].

**An operator is a function whose name is the glyph between grave accents**:

    type Point = x : u8 ; y : u8

    fn `+`(a: Point, b: Point) → Point:
        Point(.x ← a.x ⊞ b.x, .y ← a.y ⊞ b.y)

and it is called by writing the operator, `p + q`.  Nothing else about it is
special: it may be generic, have conditions, be exported.

**One parameter is the prefix reading of a glyph and two the infix one**
(4922), so `⌈` may be defined both ways, and they are two definitions.  **A
pair of brackets is an operator too**, written around what it is applied to,
its first parameter that and the rest what stands inside -- as many as it
likes:

    fn `⟦⟧`(g: Grid, i: u64, j: u64) → u8: …      ※ g⟦1u64, 2u64⟧
    fn `⸨⸩`(g: Grid, k: u8) → bool: …              ※ g⸨3u8⸩

**The language's own meanings cannot be replaced**: a definition is consulted
only where the operator means nothing for those operands, so `1u8 + 2u8` is
three in every program.  Two operands of different types are refused for one
of the language's own glyphs before a definition is looked for (4206), so a
mixed operation -- a number times a vector -- takes a glyph of its own.

**Which glyphs**: any Unicode symbol (`Sm`, `So`), the language's own
operators among them, and any opening and closing bracket (`Ps`, `Pe`) but
the ones the grammar needs.  Not a glyph the language uses for something that
is no operator (3052), not `∧ ∨ ? ⌖ ¨`, and one glyph or one pair (3051).
**A glyph the language gives no meaning** binds as tightly as `×`, to the
left, and a use with nothing defined is refused (4923):

    fn `⊛`(a: Point, b: Point) → Point: …

**An exported operator is in force wherever its module is imported**, written
without the module's name -- that is how `std` gives every type `⍕`.  Two
imports defining one glyph for one number of operands are refused (4924);
a definition in this file wins over an imported one, silently, which is how a
program says what its own type's text is ([[std.text]]).

Program:

    let std := ⎕import("std")

    type V = x : i32 ; y : i32

    fn `+`(a: V, b: V) → V:
        V(.x ← a.x + b.x, .y ← a.y + b.y)

    fn `⊛`(k: i32, v: V) → V:
        V(.x ← k × v.x, .y ← k × v.y)

    fn `⟦⟧`(v: V, i: u8) → i32:
        if i = 0u8: v.x else: v.y

    @[startup]
    fn main(init: std.Init) → u6:
        let a: V = V(.x ← 1i32, .y ← 2i32)
        let b: V = a + 3i32 ⊛ V(.x ← 1i32, .y ← ⁻1i32)
        _ ← std.println⌜&mut init.io.output, "{} {}", b, b⟦1u8⟧⌝
        0u6

Output:

    V(.x ← 4, .y ← ⁻1) ⁻1
