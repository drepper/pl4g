title: The world outside the program

Part of [[running]].

**A function follows the language's own convention**, which the compiler
chooses per function and may change.  **`@[cdecl]`** says it follows the
system's C convention and keeps its plain name -- `@[cdecl(variadic=true)]`
a variadic one; on an array variable, C's layout.  **`@[abi]`** says the same
of a function, `@[abi("sysv64")]` naming a convention the target knows
(3210); on a record it says the fields are laid out as C would and never
reordered, and only a reference to one is handed to a call (4596).  **One may
be answered whole**: by a `@[cdecl]` function as C answers the `struct`, in
registers up to sixteen bytes and through room the caller made beyond; by one
of the language's own convention always through that room.

**A value of the system's convention** is `@[cdecl] fn(i32) → i32`: the
address of code and nothing else, called as C calls it -- a named `@[cdecl]`
function where a value is wanted, or **`⎕at(ADDRESS, ⌜@[cdecl] fn(…)⌝)`**,
code at an address something else gave, believed as `⎕at` of a reference is;
**`⎕address(f)`** is where its code is.  It may be held anywhere, a variable at
the top level too, starting as `⎕at(0u64, …)`.  It does not convert to or from
`fn(i32) → i32` (4360); a lambda is never one (4361).  A call of one answers
as a named `@[cdecl]` function does, an `@[abi]` record as C answers it.

**`@[visible]`** puts a definition's symbol in the finished image for something
outside to find; `@[export]` is the other question, what files importing the
module may name ([[modules]]).  The image's own names -- `_start`, anything
beginning `__pl4g` or `pl4g_` -- are not a program's (4341).

**A shared object**, `-shared`, is a library a program in another language
loads with `dlopen`: it offers its `@[visible]` functions, each `@[cdecl]` or
`@[abi]` (5303).  It needs no startup function; its constructors run when it
is loaded and its destructors when it is unloaded.  A stop in it ends the
process, as in a program.

**A function with no body is defined somewhere else** -- the line ends after
the header -- and says where, or is refused (4593, 4594):

    @[external("pl4g_io_submit")]
    fn io_submit(r: &mut Ring, which: i32, fd: i32, at: u64, len: u64) → i64

    @[host("puts")]
    fn puts(text: str) → i32

**`@[external("SYMBOL")]`** names a function of the runtime the compiler
carries (4595 for one it does not have).  **`@[host("SYMBOL")]`** names one of
the program a shared object or the interpreter runs in, and what crosses to
it and back is what C has, text included ([[running.host]]).  Both are impure
by being defined elsewhere.

**`⎕syscall(NUMBER, ARG…)`** asks the kernel directly, with at most six
machine words (4572, 4573), answering the `i64` the kernel did, negative where
it refused; **`⎕sc@NAME`** is the call's number on the target being built
for, `⎕sc@write`, `⎕sc@pipe2` (4574, 4575).  A function asking is `@[impure]`.
**`⎕auxv(TYPE)`** is what the kernel's auxiliary vector says of an entry type
-- `⎕auxv(6)` the page size, `⎕auxv(33)` where the vDSO is -- as a `u64?`,
nothing where it said nothing, as in a shared object (4380, 4381); read once at
the start, it makes no function impure.
**`⎕at(ADDRESS, ⌜&T⌝)`** and **`⎕span(ADDRESS, COUNT, ⌜T⟦⟧⌝)`** make a place,
or a run of them, out of an address something else gave, and
**`⎕address(&x)`** is the way back; **`⎕acquire(&p)`** and **`⎕release(&mut
p, v)`** read and write with the ordering a second observer needs, and make a
function impure.  **`init.fs.adopt(fd, ⌜std.io.Writer⌝)`** makes a device of a
descriptor such a call made ([[std.fs]]).
